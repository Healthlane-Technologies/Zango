Why Free design broke

From the zango_isn_hcp build. Only one of these was something the agent could fix.

Blank references

The capture reused one browser page. Screen 5 crashed inside the imported script, and every screen after it came out as <div id="root">. On fresh pages, detail, admin-dash and admin-cases render fully.

Platform

No mapping from design to components

Default design maps every spec element to a kit component. Free design asked the agent to redraw 24 screens freehand, and classed 9 of them as "theme", which can never match.

Flow

Create case blocked

expr.py can't compare two fields on a form record, so bp_systolic > bp_diastolic always fails. The UI test can't pick a date more than 10 years back.

Platform

Built blind, fixed in bulk

51 turns written without running anything, then 2 fix rounds fed every failure together, including ones only the platform team can fix. The agent monkey-patched the runtime.

Risks

What could make this harder than it looks.

Kit coverage

ui.tsx has about 35 components. Pieces the mockup doesn't show fall back to the default and may look off-brand. List the fallbacks in the internal report.

Imported prototypes are arbitrary apps

Some screens need state that only a click path creates. If sample isn't enough, allow a short recorded click path, or mark the screen reference-only.

Diff noise

Dynamic text, fonts and data make pixel diffs flaky. Use fixed content, wait for fonts, and compare single-component crops rather than whole pages.

Session time

Each slice adds a bring-up (about 30–60 s) plus browser tests. Keep verify incremental and limit tries per slice.

Threading

Tools run on the SDK pump and must not touch the ORM. Route studio_verify through the stream.py queue and let the turn loop run the steps.

Misrouted failures

An app bug can surface inside platform frames. When a traceback also contains workspace frames, send the failure to the agent too.

Industry patterns behind this plan: GitHub Spec Kit and Kiro (gated spec → plan → tasks), Figma Code Connect and Builder.io Visual Copilot (design-to-component mapping and tokens), and visual feedback loops for coding agents (render → compare → fix before done).
