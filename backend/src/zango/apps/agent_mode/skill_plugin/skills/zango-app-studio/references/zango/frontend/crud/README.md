# Frontend CRUD references

React patterns for pages that list, edit or display CRUD data.

| Writing | Read |
|---|---|
| Any CRUD-backed page — always first | `core.md` (imports, API response shapes, `CrudHandler`) |
| A list with custom columns or a custom table body | `tables.md` |
| A detail panel or drawer on a CRUD model | `detail.md` |
| Data fetching, mutations, cache invalidation | `hooks.md` |

`core.md` alone covers an ordinary list page. Read the others only when the
page needs what they describe.
